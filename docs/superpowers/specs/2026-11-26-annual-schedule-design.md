# 年間スケジュール（クラブアカウント用）設計

- 作成日: 2026-11-26
- ブランチ: `claude/admin-annual-schedule`

## 目的

クラブアカウント（`club_account`）が、自クラブの例会の予定を月ごとのカレンダーで見渡し、
そこから例会の追加・編集・削除にすぐ移れるようにする。

## 対象と権限

- 開けるのは `club_account` のみ。
- サイドバーに「年間スケジュール」（`/schedule`）を追加する。`club_account` 以外には出さない。
- 他のロールが URL を直接開いた場合は `/dashboard` に戻す（`src/lib/auth/page-access.ts` に規則を追加）。
- 追加・編集・削除の権限チェックは、既存の例会作成画面・編集画面・`DELETE /api/meetings/[id]` のものをそのまま使う。

## 表示するデータ

- 既存の `meetings` テーブルから、自クラブ（`session.user.clubId`）の、削除されていない、表示中の月の例会を取り出す。
- 新しいテーブルや入力は追加しない。例会を登録すれば（例会作成・取り込みのどちらでも）その日付に表示される。
- 状態はすべて出す（下書き・募集中・締切・終了・中止）。色は `MEETING_STATUS_COLORS` に合わせ、中止は取り消し線にする。
- 他クラブの例会・地区行事は出さない。

## 画面

- 月カレンダー（日〜土の7列）。`?month=YYYY-MM` で月を指定し、不正な値なら今月（日本時間）にする。
- 「前の月」「次の月」「今月に戻る」。見出しに年度（7月始まり、例: 2026-27年度）を併記する。
- 凡例（状態ごとの色）を表示する。
- PC・タブレット（md 以上）: 日付のマスに「開始時刻＋例会名」を並べる。今日は丸で強調、土曜は青・日曜は赤。
- スマホ: 小さなカレンダーに状態の色の印だけを付け、日付を押すと下の一覧のその日に移る。
- カレンダーの下に、その月の例会一覧（日付順、時刻・会場つき）を出す。例会がない月は「この月の例会はありません」。

## 追加・編集・削除

- 追加: 日付のマスにマウスを乗せると「＋」を出す（スマホでは一覧の日付の下）。ページ右上の「＋ 例会を追加」もある。
  押すと `/meetings/new?date=YYYY-MM-DD` を開き、開催日が入った状態にする。
  - `/meetings/new` に `date` パラメータを追加する（`YYYY-MM-DD` 形式の正しい日付のみ受け付ける）。
  - コピー元（`?from=`）と同時に指定された場合は、指定した日付を開催日に入れる。コピー元を選び直しても日付は引き継ぐ。
- 例会を押すと概要の枠（状態・日時・会場）を出し、「詳細」（`/meetings/[id]`）「編集」（`/meetings/[id]/edit`）「削除」を置く。
- 削除: 1回目でボタンが「本当に削除」に変わり、もう1回で `DELETE /api/meetings/[id]` を呼ぶ（例会一覧と同じ2回押し方式）。
  成功したらメッセージを出してカレンダーを読み直す。失敗したらエラーのメッセージを出す。
- 枠は外側のクリック・Esc・スクロールで閉じる。

## 作り方

- `src/lib/calendar/month.ts`: 月の判定・月送り・曜日・マスの組み立てなど、カレンダー共通の関数。
  既存の地区カレンダー（`src/app/(dashboard)/district/calendar/page.tsx`）もこれを使うように置き換える（見た目・動作は変えない）。
- `src/app/(dashboard)/schedule/page.tsx`: サーバー側。ログイン・権限確認、例会の取得。
- `src/components/schedule/ScheduleCalendar.tsx`: 画面側。カレンダー・一覧・概要の枠・削除。

## 今回やらないこと

- 他クラブ・地区行事の表示
- 例会以外の予定の入力
- 印刷
- 年度（12か月）をまとめて表示する画面
- `club_account` 以外のロールへの公開

## 確認方法

- 型チェック（`tsc --noEmit`）、lint、`npm run build` が通ること。
- 権限: `club_account` 以外では `/schedule` がサイドバーに出ず、直接開くと `/dashboard` に戻ること。
- 表示: 月送り・今月に戻る・不正な `month` で今月になること、状態ごとの色、中止の取り消し線。
- 追加: 「＋」で開催日が入った例会作成画面が開くこと。不正な `date` は無視されること。
- 削除: 2回押しで削除され、カレンダーから消えること。
- 地区カレンダーの見た目・動作が変わらないこと。
